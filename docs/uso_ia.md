# Uso de Inteligencia Artificial - Proyecto Gestor de Tareas

# Modelo utilizado
ChatGPT

---

# Uso de IA en el proyecto

Se utilizó inteligencia artificial para apoyar el desarrollo del proyecto en las siguientes áreas:

- Estructura inicial del proyecto HTML
- Diseño de estilos CSS
- Implementación de funcionalidades en JavaScript
- Organización del código y buenas prácticas

---

# Prompts utilizados

- "Crear un gestor de tareas con HTML, CSS y JavaScript"
- "Agregar funcionalidades de mover tareas entre columnas"
- "Implementar validación de formulario en JavaScript"
- "Diseñar un layout tipo Kanban con CSS"

---

# Ajustes manuales

El código generado por IA fue revisado y modificado para:

- Adaptarlo a la estructura solicitada por el docente
- Separar correctamente archivos CSS y JS
- Mejorar la organización del proyecto

---

# Reflexión

La inteligencia artificial facilitó el desarrollo del proyecto, permitiendo aprender y construir una solución funcional en menos tiempo. Sin embargo, fue muy necesario revisar paso por paso la rubrica del profesor para ir guiandose en base a lo planteado.
